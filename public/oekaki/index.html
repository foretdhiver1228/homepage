작은 그림방 사용법

도구와 색을 선택하고 캔버스에 그려보세요. 레이어를 나누면 밑그림과 색칠을 따로 관리할 수 있어요.

  • P / B / E / F 펜 / 브러시 / 지우개 / 채우기
  • L / R / O / I 직선 / 사각형 / 원 / 스포이트
  • Ctrl·⌘ + Z 실행 취소
  • Ctrl·⌘ + Shift + Z 다시 실행
  • PNG 저장 흰 배경을 포함한 완성 이미지 다운로드

채우기는 선택한 레이어를 기준으로 작동합니다. 펜 압력은 압력을 전달하는 스타일러스의 브러시에서 적용됩니다. 실행 취소는 최근 15개 작업까지 가능해요.
